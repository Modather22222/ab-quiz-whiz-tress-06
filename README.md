# Quiz Whiz

A simple Flutter quiz app: 10 general-knowledge multiple-choice questions with
instant right/wrong feedback, a progress bar, and a final score screen with a
restart button. State is managed in-memory with a `ChangeNotifier`, and the UI
uses Material 3 and adapts to the system light/dark theme.

Run it with:

```sh
flutter pub get
flutter run
```

Tests: `flutter test`
